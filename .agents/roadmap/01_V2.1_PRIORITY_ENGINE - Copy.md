# V2.1 — Priority Engine

## Goal
Menentukan task yang paling penting secara deterministic.

## Inputs
- deadline proximity
- task importance
- estimated duration
- progress
- overdue status
- scheduled time
- dependencies if available
- remaining workload

## Output
- priority_score
- priority_level: LOW / MEDIUM / HIGH / CRITICAL

## Requirements
- Inspect existing task schema first.
- Reuse existing fields where possible.
- Business logic berada di service/domain layer.
- Integrasikan priority ke Today dashboard.
- Tampilkan reason/explanation bila sesuai UX.

## Test Cases
- normal task
- overdue task
- completed task
- no deadline
- distant deadline
- 0% progress
- 100% progress

Jangan merusak fungsi task yang sudah ada.

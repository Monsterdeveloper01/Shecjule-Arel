# V2.2 — Deadline Risk Engine

## Goal
Memprediksi apakah task berpotensi terlambat berdasarkan workload dan waktu tersedia.

## Inputs
- deadline
- current time
- estimated duration
- progress
- remaining duration
- available free time before deadline
- existing scheduled commitments

## Calculation
- remaining_work
- available_work_time
- completion_feasibility
- risk_score

## Output
SAFE / LOW / MEDIUM / HIGH / CRITICAL

## UI
Contoh:
Database Assignment
Due in 2 days
Progress: 35%
Estimated remaining: 4h
Available time: 2h
Risk: HIGH

Reason:
"Your remaining work is greater than your available time before the deadline."

Completed tasks tidak dihitung sebagai risk. Overdue tasks harus memiliki status khusus.

Gunakan service/domain layer dan jangan lakukan destructive database changes.

# V2.6 — Schedule Overload Detection

## Goal
Mendeteksi hari/periode yang terlalu padat.

Pertimbangkan:
- number of classes
- number of events
- number of deadlines
- total estimated task workload
- available free time
- task priority
- rest/sleep period jika tersedia

## Output
LOW / MODERATE / HIGH / CRITICAL

## Example
Thursday
4 classes
2 events
3 deadlines
Estimated workload: 6h
Available time: 3h
Risk: HIGH

Recommendation:
"Consider completing Database Assignment today."

Jangan hanya menghitung jumlah event; workload harus mempertimbangkan durasi.

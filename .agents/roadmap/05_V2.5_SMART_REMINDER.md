# V2.5 — Smart Reminder

## Goal
Reminder harus mempertimbangkan konteks, bukan hanya tanggal deadline.

Pertimbangkan:
- priority
- deadline risk
- progress
- remaining workload
- available time
- upcoming schedule

## Example
⚠️ Database Assignment
Deadline in 2 days.
Progress: 35%.
Estimated remaining: 4 hours.
Available time: 2 hours.

Recommended:
Work on it today.

## Requirements
- Anti-spam mechanism.
- Jangan mengirim reminder berulang untuk kondisi sama.
- User dapat disable smart reminders.
- Pisahkan notification engine dari delivery layer.
- Gunakan web push jika infrastructure PWA mendukung.

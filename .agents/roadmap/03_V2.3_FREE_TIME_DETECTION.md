# V2.3 — Free Time Detection

## Goal
Menemukan waktu kosong user berdasarkan:
- college schedule
- events
- appointments
- scheduled tasks
- configurable study/work hours

## Example
09:00–10:30 class
10:30–12:00 FREE
13:00–15:00 class
15:00–17:00 FREE
19:00–21:00 event

## Requirements
Buat reusable FreeTimeService.

Handle:
- overlapping events
- adjacent events
- events spanning midnight
- timezone
- past events
- current time
- minimum free-slot duration

Jangan menganggap 00:00–23:59 sebagai available. Gunakan configurable study/work hours.

Tahap ini hanya mendeteksi free time; jangan otomatis assign task.
